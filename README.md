## Sobre el proyecto

Proyecto experimental de robótica autónoma, orientado al diseño y construcción de una plataforma móvil capaz de detectar obstáculos, tomar decisiones y preservar su propia integridad física.

El desarrollo integra conocimientos de mecánica, electrónica y programación, mediante soluciones de diseño propio y un proceso de experimentación continua.
